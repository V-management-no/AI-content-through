プライバシーポリシー

制定日：2026年9月25日

1. 対象となるアプリ

本ポリシーは、「AIのつかいみちラボ」（以下「当ラボ」）が運営者本人のために作成・利用している投稿ツール（以下「本アプリ」）に適用されます。本アプリは、運営者が自身のYouTubeチャンネルに動画をアップロードする目的でのみ使用しており、一般には提供していません。

2. 取得する情報

本アプリは、YouTube API サービスを通じて、運営者本人のGoogleアカウントについて、動画をアップロードするための認証情報（アクセストークン）のみを取得します。第三者の個人情報は取得しません。

3. 情報の利用目的

取得した認証情報は、運営者本人のYouTubeチャンネルへの動画アップロードにのみ使用します。

4. 情報の保存と管理

認証情報は運営者のパソコン内にのみ保存し、外部のサーバーには保存しません。

5. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

6. YouTube API サービスについて

本アプリはYouTube API サービスを利用しています。本アプリを利用する場合、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。本アプリへのアクセス権は、Googleアカウントのセキュリティ設定からいつでも取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、Threads（@ai_tukaimichilab）のメッセージからお願いします。

8. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。
